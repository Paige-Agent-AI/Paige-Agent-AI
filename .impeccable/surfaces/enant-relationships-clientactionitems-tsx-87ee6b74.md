## State and transition map

| State | Interaction and result | Recovery and exit |
| --- | --- | --- |
| Closed | Prepare request opens inline; no private read before opening | Same record and public history remain |
| Loading | Native owner history/authority read; no editable private fields | Retry read only |
| Empty/ready | Title and instructions, 160/4000 native limits | Clear draft or collapse; keep unsaved buffer |
| Validation | Required text and field feedback; no native write | Correct the fields |
| Preparing | Disable replacement save; retain exact words | Collapse preserves the same attempt |
| Saved/prepared | Show canonical returned wording and save state | Check saved record; start another only after known save |
| Unknown/checking | Save not confirmed; no replacement mutation | Check the SAME original intent; absence is not rejection |
| Changed/linked | Withhold old words; report only the original record facts | Read the original work; no delivery/approval inference |
| History | Read original pages with raw native cursor | Newest/older and explicit refresh; no synthetic rows |
| Denied/withdrawn | Hide private data, clear buffer, stop actions | Reopen after legitimate access restoration |
| Other actor/business/client | Keyed lifecycle removes old state before effects | Resolve the new legitimate scope |
| Collapsed | Preserve draft/unknown attempt and existing unload guard | Reopen, recover or save |
