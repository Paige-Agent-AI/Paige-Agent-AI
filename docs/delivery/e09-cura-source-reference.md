## Owner outcome and original authority

An authorized publisher can open one original CURA Knowledge source inside the
existing Clients → Portal → Experience view, including a source beyond the first
inventory page. The address is a reference, never authority. Existing actor/business
context and native publisher/Knowledge permissions decide what can be read.

The existing canonical record-link destination portal_knowledge maps to the
current account's Portal with view=knowledge and an optional UUID source. The
closed parser rejects duplicate/malformed selectors and ignores supplied actor or
tenant authority. Missing/foreign sources never substitute an unrelated record.
Business/actor A→B→A and changed references retire old asynchronous results.
