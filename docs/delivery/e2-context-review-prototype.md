# EXP02 contextual review — throwaway flow contract

Owner October21 refinement supersedes blanket removal of review context. Creative
direction/implementation choices are delegated to this sole EXP02 lead; founder
evaluates the complete live Experience once. This prototype is local/synthetic,
not a released feature, authorization, provider proof or founder acceptance.

Goal: notice relevant waiting work, inspect its source, review in the existing Desk and return to the same conversation.
Human and feel: ordinary authorized SOLO owner; calm assistance with readable decisions and protected focus.
Entry and exit: contextual lower-composer suggestion; overview; spacious Decision & Opportunity Desk; return to original Chat/draft/scroll/focus.
System: retain native PAIGE shell, Schibsted Grotesk, Mineral/Obsidian, shared controls and existing navigation; no new visual world.
Signature: a quiet “Review prepared work” control unfolds a short source-backed overview in reserved layout space above the composer.
Feedback: one short expansion/focus transition, no pulse, fake urgency, prediction claim or browser vibration; reduced motion is immediate.
Rejecting: permanent context banner, capped preview posed as total, automatic approval, composer-overlay obstruction and generic edit forms.
Variants: narrow rail offers the same compact entry; substantial review uses full protected focus rather than stacked rail controls.

## State and transition map

| From | Trigger/guard | To/container | Feedback and recovery |
| --- | --- | --- | --- |
| Quiet | Unrelated page/conversation, client scope, unresolved actor or denied read | No suggestion | Existing conversation unchanged |
| Resolving | Relevant context, authorized account/actor | Quiet loading | No invented count; explicit retry only after owner opens context |
| Ready | Source-backed eligible items | Compact control above composer | Exact count only when authoritative; otherwise bounded-preview wording |
| Ready | Dismiss | Hidden for this actor/account/work set | No data mutation; identical/reordered/shrinking set stays hidden |
| Dismissed | Genuinely new eligible identity/revision | Compact control | No resurfacing merely on page render or unchanged refresh |
| Ready | Expand | Adjacent wide-screen popover / narrow Dialog sheet | No absolute overlay across composer/send/Live; Escape/close restores trigger |
| Overview | Select original item | Spacious existing Decision Desk | Original record/source/why/status; Chat stays mounted with unsent draft |
| Review | Edit original draft | Existing domain/Mission editor | Validation/dirty-exit, no cloned content store or generic writer |
| Review | Request consequential action | Original approval/authorization | No action merely from chip or overview; exact reviewed request retained |
| Authorized request | Native result | Verified result, original receipt | Source-confirmed success only; completed action is not causal business improvement |
| Authorized request | Lost/uncertain/error/expired | Recoverable original request | Reread original status; no blind resend or invented failure/success |
| Review/overview | Account, actor or context switch | Retire old private display | No stale record across identity; return only after fresh authorized read |
| Review | Close/return | Original conversation, draft, scroll and focus | No remount/reset or automatic message send |
| Any | Offline/read error/revocation | Honest withheld state | Retry authorized read, close, or return; no stale zero or false completion |
