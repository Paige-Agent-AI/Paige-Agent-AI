## Defect and current implementation

The existing Chat binding set saved from any truthy library response, ignoring RPC errors and the actual run/source records. Empty arrays, empty objects, wrong run ids, stale data delivered with an error, or a persisted parent whose sources failed to save could be described as a saved report. The service-auth engine request omitted its supported expected_tenant_id cross-check. Non2xx or malformed engine responses could default to configured=true. The failure path echoed an arbitrary exception message to the model. These are source-reproduced shared binding defects, not evidence of an Academy-specific entitlement defect or proof of a bad historical run.

Before invoking the same paige-deep-research engine, require a question and current caller-JWT workspace equal to the server persona. Send the server-resolved expected_tenant_id and verified user.id, ignoring model-supplied identity/scope. The engine remains the original implementation; expected_tenant_id remains a cross-check, not authority. Provider configuration, cost/hop/time bounds, Fabric dormant state and persistence semantics are unchanged.

Require an actual successful native HTTP response with run UUID, matching question, findings/sources arrays and explicit native coverage. A saved report requires error-free object readback from get_workspace_research_run with the exact run/question/domain/caller, coverage/status, findings, entity profile, and complete ordered source fields/timestamps. JSON object ordering and equivalent native UTC timestamp representations do not cause false mismatches. A partial parent-only persistence remains saved=false; it is not declared absent. Recheck caller workspace before publishing findings. Failed/unconfirmed invocation is bounded and does not leak provider bodies or invite automatic retry.

The existing research language contract, canonical source indices, single assistant turn/card and library RPC remain unchanged. Explicit native invocation success and the closed research_run receipt reference allow canonical settlement to describe a completed result without implying that every claim is verified or that the report is saved. Unconfigured/error/no-findings/partial language remains the existing source-owned contract. This does not create exactly-once research, durable Research Fabric preparation or full domain Rail coverage. Those proof boundaries remain open.
