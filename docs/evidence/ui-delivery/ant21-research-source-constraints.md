## Contract and ownership

`max_sources` accepts an optional integer from 1-90, narrowed to the incumbent general50/dossier90 ceiling. Each search receives at most 5 or its remaining source budget. `allowed_domains` accepts 1-20 bare hostnames, normalizes case/duplicates, and includes exact hostnames or dot-boundary subdomains. `openai.com` includes `developers.openai.com`; it never includes `openai.com.attacker`. The opaque existing `domain` topic hint is unchanged. Malformed supplied policy is refused before analytics/provider/strategy/model work. Conflicting top-level/delegated constraints are refused rather than silently dropped.

The incumbent Firecrawl wrapper sends `sources:["web"]` and documented `includeDomains`. Both wrapper and native admission independently check full URL hostname, discard credentials/non-HTTP(S) URLs and deduplicate normalized URLs before reads/synthesis/persistence. No redirects or provider configuration change. Exhausting the source budget stops further search after admitted-page reads; synthesis still binds claims to the same stable admitted source indexes. `coverage.source_policy` persists through the existing coverage JSON. Chat refuses contradictory policy/result output with an honest unknown outcome, without filtering, rerunning or claiming a saved report. An unconfirmed saved result asks for inspection of the existing library rather than inviting a fresh run; saved copy no longer promises unsupported fresh-message continuation.

Parent delegated only these Research-specific seams; all other Chat, source pins, domain runtime, migrations, ACL and release operations remain with the lead/current owners. The integration-registry provider remains PARTIAL.
