using the caller JWT and explicit query filters as well as returned-row validation. Tenantless
threads still require the existing native platform-owner answer and the handler's existing null
turn scope; no new null-profile restriction or membership-AND is introduced. Non-null turns force
the incumbent resolver plus explicit profiles.active_tenant_id equality, including when the
normal protected-evidence latch would otherwise short-circuit. The helper is used before reading
the transcript, before each provider leg, before CAS and after its readback. Failure is sticky for
that summary task; post-turn refusal cannot retroactively rewrite the parent turn's evidence latch.
Once recalled, the summary's caller/thread binding remains part of subsequent protected checks.

fabricCompletion already supports chat-shaped text, token caps, tracing, cancellation and the
canonical budget. Operational retains the old gateway's reasoning-band hard stop. Cheap would
allow gated continuation at that hard ceiling, so it is deliberately not used. Explicit2048 avoids
the OpenAI adapter's4096 default. The exact existing attribution prompt remains unchanged.

thread-summary-fold job tag, native tenant/working-context and agent attribution. TraceCtx has no
actor field: authenticated caller/thread authority is not replaced with JSON metadata.

still allowed egress after its awaited budget read, and allowed a fallback after authority changed
during primary failure. The integration lead explicitly authorized a minimal existing-seam

summary_through_seq, with one returned row required. No SQL/function/RLS change or native database
