Word text uses the original untrusted-reference fence. It cannot publish Knowledge, widen tools, follow links, sign an agreement or change a financial record. No Layer C action is needed for this bounded read; no alternative orchestration is added. Private transcripts are not copied to business Conversations or Team Hub.

The decoder reads one unambiguous UTF-8 Word body, with bounded archive membership, XML size, tag length/nesting, streaming output and time. It never extracts archive files to disk or resolves relationships. Original upload storage limits are distinct from processing limits. Ambiguous edits, encrypted/unsupported archives and oversized bodies are explicitly unread. Standard DEFLATE compression flags and both descriptor forms follow the [original ZIP specification](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT).

Node application typing resolves the two Deno names to installed API types only; there is no runtime alias or permissive any declaration. Actual Deno type checking/execution resolves the pinned production parser versions. The Vitest native-suite wrapper fails when Deno is absent in CI; local absence is a declared skip, and the recorded local verification supplied the isolated official Deno2.9.6 binary. Parser tests execute with network, environment, file, process, FFI and system access denied. Native tests are nested in the normal test run; counts are not additive.

Original ALG-01/12 bounded reconciliation/exception inputs are preserved, with no maturity promotion. ALG-02/04/13 and the original42 customer outcomes remain at their canonical evidence states. Founder Acceptance remains NOT_ACCEPTED.
