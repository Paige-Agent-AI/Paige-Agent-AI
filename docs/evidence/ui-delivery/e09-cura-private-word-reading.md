Word text uses the original untrusted-reference fence. It cannot publish Knowledge, widen tools, follow links, sign an agreement or change a financial record. No Layer C action is needed for this bounded read; no alternative orchestration is added. Private transcripts are not copied to business Conversations or Team Hub.

The decoder reads one unambiguous UTF-8 Word body, with bounded archive membership, XML size, tag length/nesting, streaming output and time. Its main part is selected by the original OPC root relationship and exact Word content type, never by a conventional filename alone. It reads only the two bounded package metadata members (64KiB each) and declared body (1MiB). It never extracts files to disk or follows external relationships. Simple internal main paths, including a root document.xml, are supported; encoded/query/fragment/traversal URIs, macro-enabled types, conflicting metadata and ambiguous edits are refused. The [original Microsoft package contract](https://learn.microsoft.com/en-us/office/dev/add-ins/word/create-better-add-ins-for-word-with-office-open-xml#understand-the-office-open-xml-document-package-structure) establishes the root relationship; the [original ZIP specification](https://pkware.cachefly.net/webdocs/casestudies/APPNOTE.TXT) establishes compression flags and descriptor forms. Original upload storage limits are distinct from processing limits.
