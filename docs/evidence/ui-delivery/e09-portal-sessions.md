## §58 call-outs

Nothing previously shipped is removed. The customer home's third tile changes from "Book a session" to "Next session" for a single-business customer, and the Book a session action stays on that tile with the same behaviour (it asks Paige with the same prompt). Everyone else keeps the old tile. The Solo New appointment drawer's separate guest flow is unchanged; the client picker is additive. The shared Deals client list (`useSoloDealClients`) now leaves out merged contacts; a contact merge already moves deals onto the surviving contact, so no live deal points at a filtered-out contact.

## Known limits

- Existing bookings are not linked to contacts (production had 0 of 5 linked); only bookings created with a client from now on reach a portal. A backfill by email is possible on request.
- Changing the client on an existing booking needs a new parameter on `update_internal_booking` and is not in this slice.
- `create_internal_booking` still accepts a merged contact if called directly; only the picker filters them.
- A collective-meeting cancel is not matched on start, so a cancel racing a move can name the old time in its notification; matching on start could cancel only some legs, which is worse.
