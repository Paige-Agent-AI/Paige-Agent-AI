## Scope and collisions

- Classification: Bug or Repair, Deep; backend edge function with a visible-flow impact.
- Affected flows: (1) Business admin approves an email/SMS draft during quiet hours or DND → sees HELD, approves again later. (2) The hours begin between the check and the send → the queued copy is cancelled to a Conversations draft whose id is recorded on the approval → approving again sends that same row. (3) The person sends that draft from Conversations, then presses Approve → the approval closes on that message, nothing sent again. (4) The person schedules that draft from Conversations, then presses Approve → told it is already scheduled, nothing sent. (5) A decline lands while send-message runs → told it was decided mid-send, with whether a copy remains. (6) The copy cannot be cancelled → told it goes out when the hold ends; a second press says the same.
- Neighboring regressions: the clear-send path, client DND/suppression/consent refusals, the send-kind 409, campaign/series/Layer-C branches — all covered by the existing tests in the same suite, all passing.
