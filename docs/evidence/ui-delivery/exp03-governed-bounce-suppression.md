Fix their address, then turn this off." The Do-not-contact switch no longer shows an address bounce as the business's pause (its writer cannot lift it); the Email row's note names the bounce instead.
- **A bounce is about the address.** The inbox now also reads this business's do-not-send rows for the contact's CURRENT main email. Change the main email and the old address's bounce neither shows nor holds Send. Another business's bounce at the same address is never read.
