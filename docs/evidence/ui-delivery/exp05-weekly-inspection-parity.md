## Root cause and universal coverage

`useWeeklyOwnerAudience` incorrectly required `useTenantContext.soloShellEnabled`, derived strictly from `tenants.features.solo_shell_enabled`. The canonical provisioning migration20270325000000 explicitly excludes that dead shell flag; the one-SOLO contract requires canonical classification rather than a per-account shell fork. This correction reuses `useTierFeatures.soloStandalone`, which calls the existing shared `isSoloStandalone` predicate. No feature flags, entitlements or memberships are changed. The real server owner predicate remains authoritative on every read; model admission and recurring controls are untouched.

The actual late `.paige-solo` reset also erased weekly Sheet padding. The retained before-insets control shows padding0. Scoped role/class rules now retain32px24px, or24px16px at phone widths, and clear the existing Close target without changing widths, maximum widths, colors, typography, motion or global selectors.
