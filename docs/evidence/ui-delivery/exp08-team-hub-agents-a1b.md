## User job and state map

- Purpose and audience: active teammates of one canonical SOLO workspace; any seat, owner or member.
- Asking: a mention of an agent in capitals (picked from the @ list or typed) is stored with the message; after the post is confirmed the asker's tab runs one turn per agent. In an agent DM every message asks that agent and no @ list is offered.
- Answer placement: a top-level question gets a top-level reply linked to it ("replying to <first name>" when not directly above); a thread question gets a thread reply.
- Private part: the channel shows the public part plus the fixed line; the asker's note follows the DM turn (writing → done with Open DM, or failed with Ask again).
- Exits: Ask again re-runs a failed turn; Check again re-sends the same request after "may not have posted" (it reads back before posting again) and, for "may still be replying" or "may still be writing your private answer", only re-reads the turn state; Esc closes the profile; Message <AGENT> in the profile opens the DM.
- Scroll owners: the conversations list, the stream, the thread or profile panel and the @ list (capped by screen height).
