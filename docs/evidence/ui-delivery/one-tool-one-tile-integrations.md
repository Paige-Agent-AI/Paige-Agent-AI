# UI delivery evidence: one tool, one tile (Solo Settings → Integrations)

This record covers the de-duplication of the Automation group. A provider the tenant had already
connected was rendering as an "add this" catalogue tile, a shipped provider tile, its own
connection tile, and again in the Popular row. Two connections read as six tiles.

UI_DELIVERY_EVIDENCE_VERSION: 1
OWNER_INTENT: The owner reported the duplication directly: "This should NEVER be a real thing because we build unified things for EVERY solo account and be ready for future solo accounts. We are a SaaS platform. Not a single person software tool." He then chose the shape himself when asked: merge into one tile in the catalogue position rather than a separate Connected group, and keep the older n8n and Zapier panels reachable from inside the connection rather than hidden or deleted. He separately ruled that a per-tenant label such as the backfill composed must not appear as a tile name on a platform every tenant shares.
