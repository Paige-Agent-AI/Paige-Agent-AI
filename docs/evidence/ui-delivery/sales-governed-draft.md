## Scope, design and state map

Goal: owner requests an exact new canonical draft and can review, decline or recover its result.
Human: Solo owner/admin; consequence clarity and continuity of the existing conversation.
Entry/exit: owner request → missing-fact question or exact card → draft report; decline returns to conversation.
System: existing PAIGE card and semantic tokens; local prototype controls are outside the proposed interface.
Signature: the server's exact total/deposit/remainder in the one existing card.
Feedback: existing report states; no native haptics claimed. Unknown is not failed or successful.
Variants: unapproved/off/expired/workspace-switched calls fail closed; phone uses the same card.

The prototype models missing-date and interrupted states locally to expose the direction; it does not implement the later C4 objective-resume or complete-package workflow. Upload, signature, hosted checkout and payment states are not applicable to this bounded draft act. Actual offer/agreement selection and collection-term linking are named subsequent S2 gaps.
