## Review and limitations

Independent review (a reviewer who did not write the code): should-fix, all fixed — the forced save could overwrite another page's draft through the (tenant, slug) upsert when Paige picked a slug already in use (a new page now always takes an unused slug, as the funnel builder does); a failed Approve lost its card; approval cards vanished on reload and the server's paige_approval_outcome was ignored (cards now restore from the latest turn's stored paige_confirm and settle on the server's outcome: done, didn't run, not confirmed); chat formatting was unreadable in the light app theme (pre, blockquote, table and link now on Studio tokens); projects started from Studio home were never renamed (a brief-titled project now counts as unnamed; a refused rename is logged once and not retried). Nits fixed: an unsaved redesign over a saved piece now shows; the not-saved copy; the reworking pill only once a step arrives; "Checking your pages" no longer shapes the sheet; the light no longer sweeps around the funnel shape. Recorded, not changed: the preview shows the generated blocks, which can differ from the arguments of a held save. Clean: preview vs saved page on the server, the preview held on protected turns, no tenant leakage, confirm frame fields, decide while sending, no stale state across projects, container sizing, reduced motion, contrast. Findings from rendering fixed before review: the wireframe rows collapsed to zero height (percentages of an indefinite height; now container units); the bottom row clipped; a duplicate placeholder line beside the steps; the top bar read "Nothing built yet" over an unsaved draft.
