## Review and limitations

Render-and-inspect findings fixed before review: the Solo reset `.paige-solo button` stripped every Studio button's fill and border (the gold Publish rendered as plain text); `.paige-solo main{overflow:hidden!important}` made the stage impossible to scroll with a wheel (the stage is no longer a `<main>`); `.paige-solo h1–h4` ink made two headings invisible on the dark surface; the home rail vanished below 980 px, taking the only visible way back; the breadcrumb repeated the title; preview fields were focus stops. FormSettings now reads pipelines for the active workspace only (RLS admits every workspace a person belongs to).

Independent review (two reviewers who did not write the code):
- Adversarial code review — blocking, fixed: reopening a project could re-send its brief and start a duplicate build (threads are per person); the timeline re-read versions on every streamed word. Should-fix, fixed: documents and copy linked to a project were treated as images; the piece list went stale after a turn; theme/SEO-only page edits and a live funnel's step edits could not be published; one malformed stream line stalled the turn; Enter before the chat was ready lost the message; a "didn't catch that" fallback after a silent but productive turn; a failed turn's steps hung under the previous reply; Publish could act on the previous piece while switching; Paige's question could be hidden in the closed narrow drawer; server permission codes reached the screen. Nits fixed: focus on open, duplicate live announcements, aria-haspopup, hardcoded colours, funnel step clamp and payment/booking steps, invalid nested HTML in card previews, stream abort on leave, stage reads by pipeline, Save without a pipeline. No defect found in RPC names/arguments, tenant scoping, Esc handling, deleted-file references, media tools or launchers.
- Design and compliance review — blocking, fixed: raw error text could reach the screen; home cards showed placeholder bars instead of the work (now a real image, a mini form from the saved questions, the page's own hero, or "Not started"); decorative gold (cost text, approval-card tint, gold stars). Should-fix, fixed: chat at 900 px sits behind a labelled "Chat" button and opens when Paige asks or works; versions preview on the stage before going back; "current" version no longer green; "Live · Manage"; no duplicate address notice; skeletons instead of bare "Loading…". Recorded, not changed: the media tools' copy names the provider key (FAL_KEY) — it is the owner-required needs-config state from the media PR and moved here unchanged; and the Studio stays dark in both app themes — a named §23 exception (the approved prototype and the previous Studio's world; the work renders on a light sheet in the tenant's brand) for the owner to overrule.
