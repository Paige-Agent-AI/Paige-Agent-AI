# EXP03 contact recipient-timezone flow prototype

THROWAWAY / LOCAL FICTIONAL DATA / NO BACKEND OR PROVIDER EFFECTS. Not production or legal-eligibility proof.

Goal: Save an explicitly supplied recipient timezone in the original contact, preserving stale/unknown recovery.
Human and feel: Current authorized business manager; clear consequence and retained draft.
Entry and exit: Original three-chapter People editor, return to the same fictional contact.
System: Original React primitives, People CSS, Solo tokens and fonts; no new application shell.
Signature: Timezone changes clear confirmation; confirming never grants consent to call/text.
Feedback: Existing local focus/status transitions, immediate reduced-motion-safe changes; no haptics.
Rejecting: Guessed device/business location, silent stale retry, false saved/unsent claims.
Variants: Owner/admin fixture; refused actor, stale record, offline, unavailable and unknown result.

| From | Trigger | Guard | To | Recovery |
|---|---|---|---|---|
| Contact | Open editor | Local fixture | Existing chapter1 | Close |
| Chapter3 | Change zone | Explicit regional value | Confirmation cleared | Correct or cancel |
| Chapter3 | Save | Valid zone/confirmation | Saving | Controls held |
| Saving | Mock success | Original contact saved | Existing saved overlay | Return/reopen |
| Saving | Mock stale | Native version changed | Draft retained; save held | Copy draft, cancel/discard and reopen latest; NEVER rebase whole patch silently |
| Saving | Mock refused | Actor changed | Draft retained; save held | Return to authorized workspace |
| Saving | Mock unknown | Answer lost | Draft retained; save held | Inspect original contact after reopening; no automatic replay/success inference |
| Saving | Mock unavailable | Candidate fields absent | Draft retained | Later explicit retry after compatible source; no fallback write |
| Any | Offline | Review control | Save unavailable | Restore connectivity |
| Dirty editor | Escape/close | Existing discard confirmation | Resume or discard | Original exits |
